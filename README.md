# Tweakly

Logiciel d'**optimisation**, de **monitoring** et de **diagnostic** pour Windows (.NET 8 / WPF).

- **Optimisation** — nettoyage, tweaks Windows / CPU / GPU NVIDIA / réseau, confidentialité, gestion et mise à jour des applications (winget).
- **Monitoring** — CPU, RAM, GPU et disques NVMe en temps réel.
- **Diagnostic** — bilan de santé du PC : état SMART et usure réelle des disques, RAM (dual channel), lien PCIe, périphériques en erreur, stabilité système (arrêts inattendus, écrans bleus, erreurs matérielles WHEA, erreurs disque, plantages de logiciels / services / pilotes), surchauffe et plantages du pilote GPU…

Mise à jour automatique intégrée via les *releases* GitHub.
